# ChatGPT Local Bridge

Desktop-only plugin for the user's own Windows PC.

This plugin launches the already-installed local bridge server from the user's profile and exposes bounded structured tools to ChatGPT Desktop. It does not expose an arbitrary remote shell.

The local installation path expected by the proxy is:

`%USERPROFILE%\\plugins\\chatgpt-local-bridge\\mcp-server.mjs`

The user can speak normally. ChatGPT chooses the appropriate local tools automatically.
